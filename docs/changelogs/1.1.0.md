# Changelog 1.1.0
This version aims to improve both the Crystal Former & Crystal Infuser

## Crystal Former
- Now requires fuel. RF can be provided instead.
- Has a custom GUI
- Slowed down, now takes about 2 minutes to complete a crystal (was 10 seconds)
- Shift clicking no longer puts items in the wrong slot

## Crystal Infuser
- Now requires fuel. RF can be provided instead.
- Has a custom GUI
